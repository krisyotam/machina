# ~/lit

Books and texts. The files themselves, not notes about them.

Shared primitives (hosts/SSH, subagent CLIs, models.env) live in
`~/.config/model/`. Read `~/.config/model/README.md` on launch and
append a row to `~/.local/state/model/log.csv` when the session ends.

## Put here

A book, a long text, a collected edition. Keep names stable.

## Put somewhere else

- Notes, reviews, comparisons → `~/research`
- Assigned course texts you want next to the syllabus → `~/edu`
- Papers → `~/sci`

## Rules

- Never delete `~/lit`.
- Do not reorganize the tree unless asked.
- Do not write new prose in here. This is a shelf.
