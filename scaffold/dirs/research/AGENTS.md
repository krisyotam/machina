# ~/research

Kept notes. Literature reviews. Investigations you would search for
again in six months.

Shared primitives (hosts/SSH, subagent CLIs, models.env) live in
`~/.config/model/`. Read `~/.config/model/README.md` on launch and
append a row to `~/.local/state/model/log.csv` when the session ends.

## Put here

Markdown (or a small directory of markdown) under a topic name:
`~/research/<topic>/`. Cite sources. Prefer one topic per directory
over one giant file.

## Put somewhere else

- A git repo → `~/src/<name>`
- A messy experiment, a clone you might throw away → `~/lab`
- A file you will delete this week → `~/tmp/<YYYY-MM-DD>-topic`
- The PDF or dataset itself → `~/sci` or `~/lit`; the write-up stays
  here and points at it
- Coursework → `~/edu`

## Rules

- Do not dump files at the root. Make a topic directory.
- Do not clone repositories into research. Research is writing.
- Do not invent a parallel `notes/` or `docs/` next to this
  directory.
- Name topics in lowercase-hyphens.
- If the work becomes a program, move the code to `~/src` and leave
  a pointer here.
