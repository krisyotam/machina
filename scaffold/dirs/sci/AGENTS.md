# ~/sci

Papers and datasets. The files themselves, not write-ups of them.

Shared primitives (hosts/SSH, subagent CLIs, models.env) live in
`~/.config/model/`. Read `~/.config/model/README.md` on launch and
append a row to `~/.local/state/model/log.csv` when the session ends.

## Put here

A paper, a dataset, a dump you will cite. Prefer
`~/sci/<topic>/` over a pile at the root.

## Put somewhere else

- The notes you take on a paper → `~/research/<topic>`
- A program that processes a dataset → `~/src` (or `~/lab` if it
  is not a repo yet)
- Course problem sets → `~/edu`

## Rules

- Never delete `~/sci`.
- Do not reorganize the tree unless asked.
- Datasets can be huge. Run `disk` before writing one here.
