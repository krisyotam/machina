# ~/music

Audio. The library, not a staging area.

Shared primitives (hosts/SSH, subagent CLIs, models.env) live in
`~/.config/model/`. Read `~/.config/model/README.md` on launch and
append a row to `~/.local/state/model/log.csv` when the session ends.

## Rules

- Never delete `~/music`.
- Do not reorganize unless asked.
- New downloads go to `~/dl` first. Move keepers here.
- Do not write project files or stems for a music program in here
  unless asked. Those belong in `~/src` or `~/lab`.
